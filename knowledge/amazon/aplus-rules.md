# A+ 规则

版本 2026-09-20.1 / Amazon US / 核验 2026-09-20。
采用模块化图文，按实际 Basic/Premium 模块确认尺寸，不把长图切片当作模块适配。
避免价格、促销、物流信息、外链、二维码与联系方式；不写 best-selling/top-rated。
不加入保证/保修信息；奖项须有颁发机构和年份支持；不做竞品对比。
使用有权使用的素材。比较模块仅选择本品牌合适商品，内容须可证实。
尽量用模块文本承载长文，预览桌面与移动端；提供准确图片替代文本。
本地 QC PASS 不等于 Amazon 发布审核通过。
