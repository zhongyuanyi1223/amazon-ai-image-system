# 主图基线

版本 2026-09-20.1 / Amazon US / 核验 2026-09-20。
公开 Amazon 员工说明要求真实产品高质量照片、纯白背景，不添加覆盖文字、装饰图形
或未包含的道具配件。产品本身真实存在的商标不能为了“无 Logo”而抹除。
清楚显示实际销售数量与完整结构，保持自然材质与接触阴影，不做插画式产品替身。

项目建议：缩略图中轮廓清晰，边缘不裁切，保留适量空间。具体占比、像素、
格式和类目例外在当前任务读取官方后台要求后写入 Image Plan，不在 Agent 中写死。
模板的 1600×1600 是可调整的项目画布建议，不是所有类目的官方硬要求。
QC 检查背景、裁切、数量、结构、叠加文字、商标真实性、实际销售内容和源图一致性。
