# 验收范围

## 本地自动验收
- 四份 Draft 2020-12 Schema 及模板可解析。
- 九个 Skill、五个 Agent 和单一隐式入口配置符合项目约定。
- 十个规范场景由 JSON 定义并由 unittest 执行，不是仅检查文件存在。
- 额外检查 P0 推断、空值、非法状态跳跃、素材变化、陈旧确认、Prompt 篡改、图片与模型不符、
  QC 矛盾、缺图/缺报告、修复上限、失败图范围、文件锁与 CLI 交付链。
- 合成 PNG 仅用于 I/O 与摘要测试，绝不代表视觉质量或真实生图通过。

## 每个团队环境须完成的在线验收
初始状态均为 NOT_RUN，不能因本地测试通过而改为 PASS。
1. 在新 clone 根目录开启 Codex，核对 AGENTS、9 Skill、5 Agent、模型配置实际加载。
2. 分别输入 tests/entry-routing.json 的五句自然语言，确认实际进入 Director。
   保存客户端/版本/日期/加载技能证据；显式调用成功不能替代隐式入口测试。
3. 上传一个真实产品的授权图片和说明，确认提问/冲突处理，核验工具实际能力。
4. 运营看到完整方案后明确确认，再真实调用原生图片工具，保存返回文件与可核验模型信息。
5. 逐图视觉 QC，至少演练一次 FAIL → 修复 → QC。最终图片身份、文字和物理关系正确。
6. 登录 Seller Central 核对当前站点、类目、主图和 A+ 模块要求；平台发布审核另行完成。

未提供真实产品且未执行生图时，交付为“项目文件与本地验证完成；在线验收待执行”，
不得报告完整生产系统 V1 全部验收通过。
